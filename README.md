# Рюкзак Кибермишки · 1 класс

Интерактивная игра перед каникулами: шесть станций, задания Совы и живая рейтинговая таблица.

## Запуск

1. Откройте `index.html` в браузере или разместите весь проект на статическом хостинге.
2. Учитель выбирает **Я учитель → Создать занятие** и показывает четырёхзначный код.
3. Дети открывают ту же страницу, выбирают класс и имя и вводят код.
4. Учитель переключает станции и открывает **Рейтинг класса** на доске.

Для подключения по коду и обновления рейтинга нужен интернет. Сохраните папку `assets` рядом с `index.html`.

## Что внутри

- 6 разных игровых форм: рюкзак, лаборатория чувств, сейф, радио, почта и билет с печатями.
- 3 попытки на каждую станцию, подсказки после ошибок.
- До 10 баллов за станцию и до 5 за дополнительные задания: максимум 90.
- Перемешанные карточки и ответы; порядок сохраняется при повторной попытке и обновлении страницы.
- Три разных PNG-совушки для выбора настроения.
- Список классов и имён, вход по коду, синхронизация результатов между компьютерами.

Статический HTML/JavaScript-проект. Сборка и установка зависимостей не требуются.
